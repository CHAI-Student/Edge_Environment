# IMPORTANT: Jetson uses NVIDIA-provided PyTorch with CUDA support
# These packages are pre-installed on Jetson JetPack:
#   - torch (with CUDA)
#   - torchvision (with CUDA)
#   - numpy (compatible version)
#   - opencv (with CUDA acceleration)
#
# Setup Instructions:
# 1. Create venv with system packages:
#    python3 -m venv --system-site-packages .venv
#
# 2. Activate venv:
#    source .venv/bin/activate
#
# 3. Install additional dependencies:
#    pip install -r requirements-jetson.txt
#
# Note: Do NOT install torch, torchvision, numpy, or opencv via pip
#       as this will override system CUDA-enabled packages
